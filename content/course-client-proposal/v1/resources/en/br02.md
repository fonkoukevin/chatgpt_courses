# BR02 — A request that needs a decision

A fictional transfer case, distinct from BR01. These amounts are exercise data, not course prices. This file supplies the brief and prices; the solution is a separate resource.

## Client S’s request

Client S requests the four BR01 pages, an FAQ and integration of the text into the website. The four pages remain in French: Home, no more than 600 words; Services, 800; About, 400; Contact, 250. No FAQ length is supplied; do not invent a volume commitment.

The **maximum overall budget is €1,200 excluding tax**. The client requests **five business days**. The capacity stated for this second case requires **at least ten business days for copywriting**.

## Supplied prices, excluding tax

| Item | Excluding-tax amount |
| --- | --- |
| Scoping and outline | €180 |
| Home | €320 |
| Services | €360 |
| About | €220 |
| Contact | €120 |
| FAQ | €200 |
| Website integration | Not priced |

No technical access, detailed scope or integration price is provided. Missing information must be requested; a ten-day capacity does not establish a firm calendar date.

## Your task

1. Calculate the full copywriting fee, separately from the ceiling and unknown integration cost.
2. Compare the requested turnaround with the stated capacity.
3. Explain incompatibilities before making a commitment.
4. If considering an option, identify the scope change, recalculate and seek explicit agreement.
5. Explain what still needs to be known before deciding on integration and the overall budget.

Produce a short response with a calculation, limits, any option and the next question. Keep it as work distinct from BR01. Adapt the checks to this case instead of treating the first case’s fee and timing as established answers.

You may decline an impossible commitment or request a choice. An alternative is not client agreement. Open the commented BR02 solution separately after your attempt.
